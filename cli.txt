# 3. HUẤN LUYỆN NHÁNH MỚI: U_FFIA27K_multimodal_kd_tournament
#    (Dual-Teacher Offline Knowledge Distillation: ConvNeXt-Tiny [Video] + PANNS-CNN6 [Audio])
#    Tích hợp Pairwise Cross-Boundary Tournament Network (B12, B23, B13)
#    End-to-End 400 Epochs (Tỷ lệ 40% nhãn thật CE + 60% Soft Target Teacher KD):
#      - Video Teacher: ConvNeXt-Tiny Holdout (Val Acc 91.07%) -> kèm cặp ConvNeXt-Nano (2.7M)
#      - Audio Teacher: PANNS_Cnn6 Holdout (Val Acc 85.57%) -> kèm cặp PANNS-CNN6-Pro (1.8M)
#      - Audio Feature Matching: Không TKEO, Không Freq Attention (đồng nhất chuẩn Log-Mel với Teacher)
#      - Tournament Fusion: Học trực tiếp từ Epoch 1 -> 400 (Discriminative LR: Fusion 1e-3, Backbones 3e-4)
#    Total Deployed Parameters: 4,673,541 (~4.674M < 5.0M strict limit) | Monitor QWK
# ==============================================================================

# 3. HUẤN LUYỆN NHÁNH: U_FFIA27K_multimodal_tournament_cross_bnd
#    (Two-Phase Warmup Training Strategy + Gated Pairwise Cross-Boundary Tournament)
#    - Phase 1 (Epoch 1 -> 200): Backbones Warmup
#        + Video: ConvNeXt-Nano 7-ch (2.701M params)
#        + Audio: PANNS-CNN6-Pro (1.827M params, no TKEO, no Frequency Attention)
#        + Fusion module: [FROZEN]
#        + Loss: Cross-Entropy cho từng nhánh riêng biệt
#    - Phase 2 (Epoch 201 -> 400): Tournament Fusion Unfreeze
#        + Mở đóng băng toàn bộ mạng (Unfreeze All)
#        + Bộ hợp nhất: Gated Pairwise Cross-Boundary Tournament Network (B12, B23, B13)
#        + Loss: Pairwise Tournament Loss + Boundary Regularization + CE Loss
#        + Bộ lập lịch OneCycleLR reset cho chu kỳ hội tụ tối ưu
#    - Tổng số tham số deploy: 4,673,541 (~4.674M < 5.0M strict limit) | Monitor QWK
#    - KHÔNG CẦN tải Teachers Offline (Huấn luyện Two-Phase trực tiếp)

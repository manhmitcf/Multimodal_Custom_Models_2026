# Bạn có 2 cách chọn cấu hình:
# Cách A (Chỉnh file JSON bằng tay): Mở config/train_config.json:
#   "video_ablation": {
#       "active_config": "C5_rgb_scalars",
#       "temporal_mode": "abs_diff"
#   }
#   Rồi chạy: python main.py
#
# Cách B (Dùng cờ CLI ghi đè trực tiếp mà không cần sửa file JSON):
#   python main.py --preset <TÊN_PRESET> --temporal-mode abs_diff
#
# Danh sách 8 cấu hình kênh:
# 1. C3_rgb              : RGB [0, 1, 2] (~2.613M params)
# 2. C4_rgb_mag          : RGB + |V| [0, 1, 2, 5] (~2.613M params)
# 3. C4_rgb_vorticity    : RGB + omega [0, 1, 2, 6] (~2.613M params)
# 4. C5_rgb_flow         : RGB + u + v [0, 1, 2, 3, 4] (~2.614M params)
# 5. C5_rgb_scalars      : RGB + |V| + omega [0, 1, 2, 5, 6] (~2.614M params)
# 6. C6_rgb_flow_mag     : RGB + u + v + |V| [0, 1, 2, 3, 4, 5] (~2.615M params)
# 7. C6_rgb_flow_vorticity: RGB + u + v + omega [0, 1, 2, 3, 4, 6] (~2.615M params)
# 8. C7_full             : RGB + u + v + |V| + omega [0..6] (~2.616M params)

# ==============================================================================
# CẤU HÌNH HIỆU CHỈNH LEARNING RATE (LR SCHEDULER)
# ==============================================================================
# Hệ thống hỗ trợ 3 chính sách learning rate:
# 1. "onecycle" (Mặc định): OneCycleLR cosine annealing theo từng batch (warmup 5% epochs).
# 2. "cosine": CosineAnnealingLR giảm dần theo từng epoch (T_max = epochs, eta_min = 1e-6).
# 3. "constant" (hoặc "none"): Cố định LR mặc định không hiệu chỉnh qua các epoch!
#
# Cách A: Chỉnh trong config/train_config.json:
#   "training": {
#       "learning_rate": 0.001,
#       "lr_scheduler": "constant"
#   }
#
# Cách B: Dùng cờ CLI:
#   python main.py --lr-scheduler constant
